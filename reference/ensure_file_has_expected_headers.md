# Ensure file has expected headers

Ensure file has expected headers

## Usage

``` r
ensure_file_has_expected_headers(path, expected_headers = c("x", "y", "time"))
```

## Arguments

- path:

  Path(s) to the file.

- expected_headers:

  Expected column name(s) to be present among the header names. Default
  is c("x", "y", "time").
