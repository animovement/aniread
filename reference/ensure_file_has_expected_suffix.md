# Ensure that the file has one of the expected suffix(es).

Ensure that the file has one of the expected suffix(es).

## Usage

``` r
ensure_file_has_expected_suffix(path, expected_suffix)
```

## Arguments

- path:

  Path(s) to the file.

- expected_suffix:

  Expected suffix(es) for the file. If NULL (default), this check is
  skipped.
