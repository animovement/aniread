# Read AnimalTA data

Read a data frame from AnimalTA

## Usage

``` r
read_animalta(path, detailed = FALSE)
```

## Arguments

- path:

  An AnimalTA data frame

- detailed:

  Animal export either raw (default) or detailed data files. We only
  have limited support for detailed data.

## Value

a movement dataframe

## References

- Chiara, V., & Kim, S.-Y. (2023). AnimalTA: A highly flexible and
  easy-to-use program for tracking and analysing animal movement in
  different environments. *Methods in Ecology and Evolution*, 14,
