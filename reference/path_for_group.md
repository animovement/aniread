# The path one group is written to

The path one group is written to

## Usage

``` r
path_for_group(path, values)
```

## Arguments

- path:

  The path given to
  [`write_dataset()`](https://animovement.dev/aniread/reference/write_dataset.md).

- values:

  A one-row data frame of the group's key values.

## Value

A file path.
