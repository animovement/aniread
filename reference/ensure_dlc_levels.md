# Check that a header has the levels DeepLabCut writes

Check that a header has the levels DeepLabCut writes

## Usage

``` r
ensure_dlc_levels(columns, path)
```

## Arguments

- columns:

  Column levels, as from
  [`dlc_columns()`](https://animovement.dev/aniread/reference/dlc_columns.md).

- path:

  The file they were read from, for the message.
